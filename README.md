# downLoader

Консольный скрипт на Python 3 для измерения скорости скачивания.
Использует только стандартную библиотеку, устанавливать зависимости не нужно.

## Запуск

Из папки `downLoader`:

```bash
python3 main.py "https://example.com/image.jpg"
```

Замените адрес на URL нужного файла. Поддерживаются HTTP и HTTPS.
Справка: `python3 main.py --help`.

## Как работает

Скрипт делает 10 последовательных GET-запросов к одному адресу. Перед следующим
запросом полностью читает тело предыдущего ответа блоками по 64 КиБ.
Файл на диск не сохраняется и целиком в памяти не хранится.

После завершения выводятся:

- Среднее время запроса в секундах: сумма времени всех загрузок / 10.
- Общий объём тел ответов в байтах и мебибайтах (МиБ, 1 МиБ = 1 048 576 байт).
- Скорость в МиБ/с: общий объём / суммарное время загрузок / 1 048 576.

Время измеряется монотонным таймером от начала запроса до полного чтения ответа,
включая установку соединения, ожидание сервера и переходы по перенаправлениям.
Заголовки HTTP и сетевые накладные расходы в объём не входят.
Скрипт запрашивает ответ без сжатия (`Accept-Encoding: identity`).
Результат характеризует загрузку с выбранного адреса, включая задержки сервера.

Тайм-аут блокирующей сетевой операции — 30 секунд; это не ограничение на время
скачивания всего файла. При сетевой ошибке, HTTP-ошибке (например, 404) или
обрыве ответа с указанным `Content-Length` скрипт выводит ошибку в stderr
и завершается с кодом 1 без итоговой статистики и повторных попыток.
Некорректный адрес или аргументы приводят к коду 2, успешное выполнение — к коду 0.
